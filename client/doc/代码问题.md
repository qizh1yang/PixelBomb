# PixelBomb 代码问题记录 (Code Issues Log)

此文档用于记录开发过程中遇到的报错、逻辑缺陷及其解决方案。

---

## 2026-05-11

### 1. 坐标转换方法失效 (Nonexistent function 'to_local')
*   **现象**：调用 `panel.to_local()` 报错 `Nonexistent function`。
*   **原因**：Godot `Control` 节点在某些环境下对该方法的支持不一致。
*   **方案**：改为使用底层的变换矩阵逆矩阵：`panel.get_global_transform().affine_inverse() * g_pos`。

### 2. 节点类型不匹配 (Type Mismatch: Control vs Node2D)
*   **现象**：`Trying to assign value of type 'Control' to a variable of type 'Node2D'`。
*   **原因**：脚本声明为了 `Node2D`，但 `.tscn` 场景文件中的节点类型仍为 `Control`。
*   **方案**：在未批量更改场景节点类型前，保持脚本声明与场景一致（统一使用 `Control`）。

### 3. 变量作用域冲突 (Redeclaration of variables)
*   **现象**：`Parse Error: There is already a variable named 'gridPos'/'panel' declared in this scope`。
*   **原因**：在重构逻辑或注入调试代码时，在同一作用域内重复定义了变量。
*   **方案**：清理冗余声明，确保变量在同一块内唯一。

### 4. 字典与节点赋值冲突 (Dictionary to Control assignment)
*   **现象**：`Trying to assign value of type 'Dictionary' to a variable of type 'Control'`。
*   **原因**：为实现“拾取偏移”功能，将 `drag_data` 改为了字典，但赋值给 `_active_drag_data` 时未解包。
*   **方案**：先从字典中取出 `.node` 再进行赋值。

### 5. 背包面板偏移飞出屏幕 (UI Offset Issue)
*   **现象**：开启宝箱分屏模式时，背包面板移动到了屏幕外。
*   **原因**：直接修改 `position:x` 且未考虑根节点锚点变化。
*   **方案**：改用 `offset_left` 和 `offset_right` 进行锚点偏移量补间动画，确保在所有分辨率下位置稳定。

### 6. 拖拽精度缺失 (Drag Precision Issue)
*   **现象**：物品放置位置不精准，无法“所见即所得”。
*   **原因**：未考虑拾取时的鼠标点击偏移，默认将鼠标作为物品左上角。
*   **方案**：实现 `pickup_offset` 机制，在 `_get_drag_data` 中记录偏移并在计算时减去。
