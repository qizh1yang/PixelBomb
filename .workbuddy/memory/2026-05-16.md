- game_mode.gd 上限字段：maxBombsCap / explosionRadiusCap / maxShieldsCap / speedCap

## 威力改为四维方向显示（完成）

### 修改文件
- `PlayerStatusCard.tscn` — PowerRow 中移除 PowerLabel，新增 PowerGrid(GridContainer, 2列) 含 UpLabel/RightLabel/DownLabel/LeftLabel（字号9px，居中）
- `PlayerStatusCard.gd` — update_stats() 移除 power/max_power，改为 8 个方向参数；新增 4 个 @onready 方向 label 引用
- `hud.gd` — update_player_stats() 同步扩展签名透传 8 个方向参数；兼容 updateStats() 从 _r_up 等旧参数推算四维威力
- `game_mode.gd` — tick() 中计算各方向实际威力 = mini(currentRadius, explosionRadiusCap + radiusXxxCap)

### 数据模型
- `player_controller.gd`: currentRadius(统一当前威力), explosionRadiusCap(基础上限), radiusUpCap/DownCap/LeftCap/RightCap(方向额外上限)
- 各方向实际威力 = min(currentRadius, explosionRadiusCap + radiusXxxCap)
- 各方向上限 = explosionRadiusCap + radiusXxxCap
